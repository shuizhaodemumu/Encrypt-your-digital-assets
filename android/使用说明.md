# 安卓视频授权工具 · 0.1.0 预览版

## 电脑与手机分开安装

- Windows 电脑：双击 `video-admin.exe`（或同内容的“安卓视频授权管理员.exe”）打开图形界面；无需命令行和 Rust 环境。
- 安卓手机：安装 `EncryptVideo-0.1.0-arm64.apk`。仅 ARM64，当前真机验证为 Android 16。
- 这是专用于安卓的视频授权工具，与原 Windows 授权管理员相互独立。不要混用两套发行密钥、内容包或 LIC。

## 图形界面操作

1. 输入至少 8 字符的口令，点击“新建发行密钥”保存；已有密钥则选择对应文件并输入原口令。
2. 选择原视频，点击“生成安卓加密视频 .eav”，保存到一个新的文件名。
3. 把 `.eav` 发到手机。安卓播放器导入后点击“获取本机设备识别码”，保存加密 JSON 并传回电脑。
4. 在电脑右侧选择同一 `.eav` 和该设备 JSON，设置授权天数与首次导入窗口（秒、分钟、小时或天）。
5. 点击“核对并签发安卓 LIC”，检查确认窗口，再保存 LIC 并发送到对应手机。
6. 手机在首次导入窗口内导入 LIC，验证成功后全屏循环播放。轻触唤出控制栏，1 秒无操作后收起。

授权天数从首次成功激活起算；重复导入同一 LIC 不重新计时。窗口期从签发时起算，默认 60 分钟。

口令不保存到配置文件。请备份发行密钥、口令以及加密视频旁的 `.eav.adminmeta`；不要把这些交给接收方。接收方只需要 APK、`.eav` 和匹配的 `.lic`。卸载手机应用/清除其数据会丢失设备密钥，需要重新申请授权。

## 范围

当前使用“独立播放器 APK + 加密视频包”，不生成每个视频一个 APK。不含 Office、开机自启动或 Root 重启守护。普通截屏/录屏的画面保护已实测；Root 修改系统和外部拍摄仍可能绕过。尚未验证所有安卓版本与视频编码。

电脑端采用与 Windows / Ubuntu 管理员一致的淡紫色背景、双栏卡片与小龙娘图标。中英切换覆盖主要工作台文字；部分校验错误和系统对话框仍为中文或跟随系统语言。

## 命令行兼容

仍可通过 `video-admin.exe --help` 查看命令。CLI 使用 `EAV_ISSUER_PASSWORD` 环境变量；图形界面无需设置环境变量。

```text
video-admin init issuer.issuerkey
video-admin pack issuer.issuerkey original.mp4 video.eav
video-admin issue issuer.issuerkey video.eav device.json video.lic 30 3600
```
