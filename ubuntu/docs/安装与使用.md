# Ubuntu 版安装与使用

适用于 Ubuntu x86_64 桌面。已实际测试的系统版本请参阅 `VALIDATION.md`。此安装包内含播放、PDF 查看和 Office 组件，不需要安装 Rust、Cargo、Docker、VLC 或 LibreOffice。

## 安装管理员程序

推荐将 `encrypt-assets-ubuntu_0.1.0_amd64.deb` 复制到 Ubuntu，用系统的软件安装器打开并安装，然后在应用菜单中搜索 **Encrypt your digital assets**。

也可以在安装包所在文件夹打开终端，执行：

```sh
sudo dpkg -i ./encrypt-assets-ubuntu_0.1.0_amd64.deb
```

若不希望安装到系统目录，可使用便携包：

```sh
sh ./Encrypt-assets-Ubuntu-0.1.0-release-x86_64.run
```

便携包不需要管理员权限。第一次运行会校验并解压自带组件，需稍等片刻；后续复用已解压组件。安装文件约 370 MiB，解压后约 910 MiB，建议至少留出 2 GiB 空间，另外预留原文件与打包内容的空间。

两个入口使用相同程序，任选一种即可。应用菜单入口仅供手动打开，**不是开机或登录自启动项**。

## 加密、授权与播放

1. 管理员先新建发行密钥并设置口令，保存 `.issuerkey` 备份。以后使用同一口令加载这份密钥。密钥和口令丢失无法从内容程序恢复。
2. 选择视频、音频、文档、图片或 PPT，再选择保存位置，生成加密内容 `.run`。不要把 `.issuerkey` 或旁边的 `.olmeta` 管理员文件发给接收方。
3. 接收方只需要内容 `.run`。赋予执行权限后打开，或在终端运行 `sh ./内容名称.run`，点击“获取本机设备识别码”，把导出的加密 `.json` 发回管理员。
4. 管理员加载原发行密钥，选择对应内容程序和设备 `.json`，设置授权天数与首次导入窗口，确认并保存 `.lic`。
5. 接收方在内容程序中点击“导入固态链密钥文件”，导入 `.lic`。有效授权才会播放或查看；以后手动打开时会恢复尚未到期的授权。

首次导入窗口从签发时开始计时；使用期限从第一次成功激活开始。重复导入同一 LIC 不会延长使用期限。

内容 `.run` 已包含运行库，接收方无需先安装管理员程序。每个新内容程序会包含一份运行库，因此小文件的打包程序也约 370 MiB；同一版本在同一用户下运行时共享解压后的组件。

## 播放方式

- 视频：授权后全屏、控制栏自动隐藏、单视频循环。空格暂停/继续，左右键跳转，F11 切换全屏，Esc 退出全屏；移动鼠标显示控制栏。
- 音频：VLC 解码播放，可暂停、跳转和调节音量。
- PDF / 文本文档 / 图片：程序内部只读查看。
- Word / ODT：打包时由内置 Writer 转为 PDF，然后加密；接收方查看的是转换后的文档。
- PPT / PPTX / ODP：原文件加密，授权后进入 Impress 放映，不转成静态 PDF。排版、字体、动画与嵌入媒体以 LibreOffice 的兼容性为准。

Windows 内容 EXE 不能直接在 Ubuntu 中使用，需要在本版重新打包并签发 LIC。

## 数据位置与卸载

发行者备份、内容程序、设备请求和 LIC 保存在你选择的位置。授权状态位于 `~/.local/share/encrypt-assets-ubuntu`，自带组件位于 `~/.local/share/encrypt-assets-runtime`（设置了 `XDG_DATA_HOME` 时采用该路径）。

DEB 程序可用系统软件管理器卸载。卸载会保留用户的密钥、授权状态和运行库，避免误删授权；需要彻底清理时，先备份你要保留的发行密钥和管理记录，再处理上述用户目录。删除授权状态后可能需要重新签发许可。

本版不安装任何开机自启动项。运行监测仍保留：播放故障可重启该内容程序，10 分钟内第三次故障会请求系统重启；正常关闭、暂停、循环结束和授权到期不计入故障。
