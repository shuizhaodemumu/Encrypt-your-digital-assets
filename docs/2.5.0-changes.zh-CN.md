# Windows 2.5.0 / Ubuntu 0.1.1

- Windows 工作台对齐 Ubuntu：淡紫全窗口背景、半透明圆角双栏卡片、圆角输入框、页眉语言按钮和文件状态提示；预览时保留紧凑操作区。
- 两端统一采用梦梦 H3 的抱锁龙娘形象，经透明图标适配后嵌入多尺寸 ICO/PNG。Windows 安装入口和新内容 EXE 继承图标；Ubuntu 菜单、窗口、DEB/RUN 均包含图标。
- 内容加密、签名 LIC、设备绑定和视频循环代码未改变。Windows 已授权内容的登录启动行为保留；Ubuntu 不添加自启。
- 老内容程序内置旧播放器/图标，管理员更新不会自动修改已分发文件。

验证详情见 VALIDATION.md 和 ubuntu/VALIDATION.md；源代码和成品分别发布为 v2.5.0 / ubuntu-v0.1.1。
