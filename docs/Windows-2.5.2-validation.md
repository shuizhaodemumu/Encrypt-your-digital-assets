# Windows 2.5.2 — PowerPoint 受控放映修复

2026-11-04。继续本地 PowerPoint，不引入私钥输入或 .olmeta 导出权限。

## 改动

- 订阅 PowerPoint 的 PresentationBeforeSave / PresentationBeforeClose / SlideShowEnd 事件，按 COM 对象身份识别本次受保护文稿，取消常规保存和另存为；其他文稿的保存不受影响。
- 主动退出前先标记放弃修改、清除本次放映绘制的批注，再退出和关闭。用户结束放映后也进入受控关闭流程。
- Office 的墨迹提示与保存提示是不同流程。仅对 PID、直接 owner 均匹配本次放映窗口的 NUIDialog，确认中英文墨迹提示及丢弃按钮后，通过 UI Automation 选择丢弃；不修改 Office 全局设置。
- 明文临时文件标记为临时、不供索引；原有分块写入、只读和退出清理保留。新增独占 session.lock；应用启动时仅回收锁已释放的本软件会话目录，不删除活跃会话。
- LIC 默认使用原始文件 stem：逐梦.pptx → 逐梦.lic。用户仍可在保存对话框修改名称。
- PPT 等文档继续禁用自启动和重启看门狗；保留授权有效性校验及放映结束清理。视频策略不变。

## 实际验证

1. 常规测试：26 通过，3 项需桌面/素材的测试默认忽略。
2. 另行执行真实 PowerPoint 保存测试：Save 与 SaveAs 共拦截两次，原文件字节未变化，未生成 forbidden.pptx；另一份文稿保存成功。
3. 另行执行带绘制批注的退出测试：host、Esc、WM_CLOSE、最后一页结束四条路径完成。首次测试发现独立墨迹提示，加入本次窗口专用处理后回归通过。该处理可能短暂显示墨迹丢弃提示，不宣称所有弹窗永不出现。
4. 真实端到端：生成逐梦.exe，导出加密设备文件，管理员界面默认逐梦.lic，签发并导入，PowerPoint 启动放映；另存为未生成副本；绘制墨迹后 Esc 退出完成；本会话 content-*.pptx 明文已删除。
5. 独占锁测试：活跃会话文件保留，释放锁后孤儿目录回收。
6. Gemini 桥接选择 safe-unit，实际退出码 0；计划给出跨 Office 语言/窗口归属等覆盖缺口，最终报告文本为空，不视为完整独立验收。上述 PowerPoint 和 GUI 测试由 Codex 执行。

## 边界

这是受控放映加固，不是 DRM。不能承诺阻止管理员权限下的内存/临时文件提取，也未覆盖 SaveCopyAs、所有导出 API、所有 Office 插件或各版本自动恢复缓存。未修改/清空用户的 Office 恢复目录，以免影响其他文档；清理仅限本程序管理的临时会话。当前墨迹提示自动处理适配已实测的中文 Office，并匹配英文文案；其他语言、窗口 owner 结构改变可能需要适配。

旧 EXE 包含旧查看器代码，不会因管理员更新自动修复；需要重新打包。发行者密钥和 .olmeta 继续仅由管理员保管。
